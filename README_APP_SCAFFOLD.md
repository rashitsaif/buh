# App scaffold

Первый безопасный этап MVP: минимальный React + TypeScript + Vite каркас приложения.

## Команды

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

## Ограничения этапа

На этом этапе не подключены:

- авторизация;
- база данных;
- платежи;
- AI/API-интеграции;
- внешние сервисы;
- налоговая бизнес-логика.
